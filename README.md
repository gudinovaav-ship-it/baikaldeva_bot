# baikaldeva_bot
Бот для женского онлайн журнала Байкальская Дева
ИИ-ассистент для «Байкальской Девы» с
Персональная анкета при первом входе (Онбординг за 1 минуту)
Бот задает женщине всего 3–4 вопроса:
«Во сколько ты обычно просыпаешься?» (например, в 07:30).
«Какая сфера сейчас больше всего требует внимания?» (энергия/выгорание, границы и умение говорить «нет», отношения, карьера, дети).
«В каком темпе тебе удобнее получать подсказки?» (только короткий текст на 1 минуту, голосовое аудио или 3 главных тезиса).
Шаг 2. Утренний персональный дайджест (ровно в её 07:45)
Бот присылает ей не «общую простыню новостей», а персональную настройку на сегодня:
Фокус дня (Soft Skill): «Сегодня тренируем навык Границы без чувства вины».
Мысль из журнала «Байкальская Дева»: Короткая выжимка из вашей статьи (2–3 абзаца).
Микро-действие дня: «Перед тем как ответить коллеге на просьбу "возьми еще задачу", сделай паузу на 3 вдоха и скажи: "Я сверюсь с графиком и вернусь с ответом к 15:00"».
Эстетика момента: «Завари чай с мятой и выпей первые 5 глотков без экрана телефона».
